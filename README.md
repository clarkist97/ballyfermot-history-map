# Ballyfermot History Map

Stories about Ballyfermot, Dublin 10, placed on a map.

Live site: https://clarkist97.github.io/ballyfermot-history-map/

## Adding or editing a story

For now, edit the `STORIES` array in `index.html`. Use the same fields as the story register. The spreadsheet is for working privately; do not add it or contributor contact details to this repository.

## Using the Google Sheet later

Publish the sheet's **Map feed** tab as CSV, then paste its published CSV link into `SHEET_CSV_URL` in `index.html`.

## Ground rules

- Every story must have sources.
- A human reviewer must approve each story.
- Only stories marked **Approved** are shown publicly.
- Never put personal data or the story register spreadsheet in this repository.
